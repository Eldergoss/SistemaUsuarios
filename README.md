# SistemaUsuarios

SistemaUsuarios es una aplicación desarrollada en Java como proyecto de aprendizaje de Programación Orientada a Objetos (POO).

El proyecto implementa un sistema de gestión de usuarios con persistencia en SQLite mediante JDBC, aplicando una arquitectura basada en el patrón Repository para separar la lógica de negocio del acceso a los datos.

Actualmente permite administrar usuarios con distintos niveles de permisos (Usuario, Administrador y SuperAdministrador), realizar operaciones CRUD sobre la base de datos e implementar un sistema de autenticación para el inicio de sesión.

## Tecnologías

* Java
* SQLite
* JDBC
* Git y GitHub
